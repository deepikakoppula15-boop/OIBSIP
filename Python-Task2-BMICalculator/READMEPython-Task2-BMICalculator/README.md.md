# BMI Calculator

## Description

This project is a simple BMI Calculator developed using Python.

The program calculates Body Mass Index (BMI) based on the user's height and weight.

## Features

- Takes height as input
- Takes weight as input
- Calculates BMI
- Displays the BMI value
- Provides the BMI category

## Technology Used

- Python

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the Python file.
4. Enter your height and weight when prompted.
