# BMI Calculator

This is a Python BMI Calculator project.

## Features

- Calculate BMI
- Show BMI category
- Input validation
- Clear button
- Save BMI history
- View history
- Show BMI graph

## Technologies

- Python
- Tkinter
- SQLite
- Matplotlib

## How to Run

Open `main.py` in VS Code and run the program.

## BMI Categories

- Below 18.5 - Underweight
- 18.5 to 24.9 - Normal
- 25 to 29.9 - Overweight
- 30 or above - Obese
